The fixed-boundary network

A FixedBoundaryNetwork is a second network method beside the multiplier network: the configuration of one time level is the parameter vector of a spatial network that carries the problem's side data, and the slab between two levels carries a bubble of St hidden units. There are no multipliers. The coupling FixedBoundary carries the previous level's parameters and the momentum that level received, and hands the momentum of the solved level on; the ansatz takes this coupling and nothing else.

The default solver of the method is LevenbergMarquardt, which damps the step by a shift on the singular values of the Jacobian; LevenbergMarquardt(variable_projection = true) eliminates the bubble's output weights in an inner solve.

The default guess, Continuation, starts the solved level at the previous level's parameters and the bubble at the previous slab's, and at the first slab at the datum and at bubble_start. A FitTo fits with the ansatz's default_fit, BubbleGreedy, the one fit method a fixed-boundary network takes. Its target Predictor is a Störmer–Verlet run of the slab on a uniform grid: the guess fits the level to the predictor's top, and the bubble to what the predictor has beyond the interpolation of the two levels.

The solve may fail, so each example prints the run's stats and claims nothing about them.

using MultisymplecticIntegrators

problem = Wave.problem(timespan = (0.0, 0.2), timestep = 0.1, xstep = 0.05)
ansatz = FixedBoundaryNetwork(Sx = 4, St = 4, xspan = (0.0, 1.0), ncells = 8)
result = integrate(problem, SpaceTimeGalerkin(ansatz, FixedBoundary()))
result.stats
(iterations = [300, 300], residuals = [0.0001128662273850229, 0.00162718881862544], initial_residuals = [0.2147165348599311, 0.1351720671800994], converged = Bool[0, 0])
method = SpaceTimeGalerkin(ansatz, FixedBoundary();
    initial_guess = FitTo(Predictor(); method = BubbleGreedy()))
result = integrate(problem, method)
result.stats
(iterations = [300, 300], residuals = [0.00011365161320355568, 0.0010867698714846683], initial_residuals = [0.004251160878053982, 0.00826376941380561], converged = Bool[0, 0])
