MultisymplecticIntegrators.LagrangianDensity — Type
LagrangianDensity(L, u, v, w; params = NamedTuple())

The Lagrangian density L(u, v, w; params) of a field theory in one space dimension, where v = ∂ₜu and w = ∂ₓu, together with its three partial derivatives ∂u, ∂v and ∂w.

L, u, v and w are symbolic. Each of the four functions is built once by Symbolics.build_function(…; expression = Val(false)), so an evaluation is an ordinary Julia call and not a re-derivation of the expression. The names of params are the parameters of the density: every built function takes their values as further positional arguments.

Fields

  • L(u, v, w, p...): the density.
  • ∂u(u, v, w, p...), ∂v(u, v, w, p...), ∂w(u, v, w, p...): its partial derivatives.
  • names: the names of the parameters, in the order of the built functions' arguments.
  • params: the default parameter values.

Example

using Symbolics
@variables u v w
d = LagrangianDensity(v^2 / 2 - w^2 / 2, u, v, w; params = (c = 0.5,))
d(0.0, 1.0, 0.0, (c = 0.5,))   # the density, with the parameters named
d.∂v(0.0, 1.0, 0.0, 0.5)       # ∂L/∂v, with the values in argument order

MultisymplecticIntegrators.LagrangianEquation — Type
LagrangianEquation{P} <: GeometricEquation

The equation of a Lagrangian field theory in one space dimension, with parameters of type P.

It carries no data of its own: the density lives in the problem, because every problem of this kind is a different density. The type exists so that a LagrangianPDEProblem has the equation type its GeometricProblem supertype needs.

MultisymplecticIntegrators.LagrangianPDEProblem — Type
LagrangianPDEProblem(density; D = 1, ics_function, bcs_function, exact_u, exact_v, exact_w,
                     timespan, timestep, xspan, xstep, params = density.params)

A Lagrangian field theory in one space dimension on a space-time slab, with a generic element type.

density is a LagrangianDensity. ics_function(x, params) returns the named tuple (u = …, v = …, w = …) of the initial data on the vector x of grid points; each entry is a vector of length D * length(x), laid out component-major, θ = [θ¹; θ²; …], so that one scalar ansatz serves every component. bcs_function(times, params) returns the boundary data of the slab whose two times are times = (t₀, t₁): the exact values on the bottom and top traces, at the grid points of xspan and xstep, and at the two ends of xspan, at both times. exact_u, exact_v and exact_w are (t, x, params) functions, or nothing where the problem has no exact solution.

timespan, timestep, xspan and xstep are converted to the element type T of timespan. The functions of the problem take its parameters, never a module-level default.

problem = LagrangianPDEProblem(density;
    ics_function = (x, p) -> (u = …, v = …, w = …),
    bcs_function = (times, p) -> …,
    timespan = (0.0, 1.0), timestep = 0.1, xspan = (0.0, 1.0), xstep = 0.01)

MultisymplecticIntegrators.SpaceTimeAnsatz — Type
SpaceTimeAnsatz

Abstract type of a space-time ansatz of one slab.

An ansatz discretises the field u and its derivatives v = ∂ₜu and w = ∂ₓu on the slab, and gives the integrator the basis functions and the Jacobian from which it assembles the residual. It is a GeometricMethod, so GeometricIntegrator(problem, method) accepts it.

MultisymplecticIntegrators.SpaceTimeQuadrature — Type
SpaceTimeQuadrature{T}

Composite Gauss–Legendre rule on one space-time slab.

The rule takes n Gauss–Legendre nodes per cell in each direction, placed between the breakpoints tbreaks of the normalised time coordinate t̂ ∈ [0, 1] and xbreaks of the physical space coordinate x. Because a cell's rule is exact for polynomials of degree 2n − 1, the composite rule integrates t̂ᵃ xᵇ exactly for a ≤ 2n − 1 and b ≤ 2n − 1 on any mesh, uniform or not.

The four boundary point sets of a slab are bottom and top, at t̂ = 0 and t̂ = 1 across the x nodes, and left and right, at the two ends of xspan across the t̂ nodes.

q = SpaceTimeQuadrature{Float64}(3; xbreaks = [0.0, 0.5, 1.0])
q((t, x) -> t^2 * x)     # the rule applied to a function of (t, x)

GeometricBase.integrate — Method
integrate(problem::LagrangianPDEProblem, method::SpaceTimeAnsatz; kwargs...)
integrate(integrator::GeometricIntegrator)

Integrate problem with method and return the named tuple (; solution, traces).

solution is the GeometricSolution on the output grid, and traces holds one entry per stored step: the top trace (u, v, w) of that step at the nodes of the space quadrature, as the method's top_trace gives it, or nothing where the method keeps none. The trace is needed at the quadrature nodes rather than the interior ones because the energy diagnostics integrate it there, at the accuracy of the Gauss rule.

The steps are driven one at a time, because the trace of a step exists only while its cache does. As in the ecosystem's integrate!, a step whose state holds a NaN ends the run with a warning; traces then ends at that step, and the solution holds the NaN there. The keyword arguments go to the integrator's constructor, and to nothing else.

MultisymplecticIntegrators.Wave — Module
Wave

The scalar wave equation ∂ₜ²u − c² ∂ₓ²u = 0 on x ∈ [0, l], with the standing-wave exact solution of the two lowest harmonics.

The Lagrangian density is L = ½v² − ½c²w², and the exact solution is

\[u(t, x) = (A₁\cos(πct/l) + B₁\sin(πct/l + π/6)) \sin(πx/l) + (A₂\cos(2πct/l) + B₂\sin(2πct/l + π/6)) \sin(2πx/l),\]

with v = ∂ₜu and w = ∂ₓu its derivatives.

problem = Wave.problem(timespan = (0.0, 3.0), timestep = 0.3, xstep = 0.01)

MultisymplecticIntegrators.VectorWave — Module
VectorWave

The wave equation for a field u ∈ ℝᴰ on x ∈ [0, l] with zero Dirichlet data, the density

\[L = \tfrac{1}{2}|u_t|^2 - \tfrac{c^2}{2}|u_x|^2 - \tfrac{m^2}{2}|u|^2 - \tfrac{\beta}{4}|u|^4,\]

the exact solution of the uncoupled case m = β = 0, each component a standing wave of Wave with amplitudes of its own, and the angular momentum J = ∫ (u₁ ∂ₜu₂ − u₂ ∂ₜu₁) dx of the D = 2 field.

L is invariant under a rotation of (u, v, w), so J is conserved; a numerical integration that loses it has lost the symmetry, which is the oracle of the vector case. The default parameters give the two components different phases, so that J is not zero.

problem = VectorWave.problem(timespan = (0.0, 1.0), timestep = 0.1, xstep = 0.05)

The density of a component-major vector field u ∈ ℝᴰ: the scalar density summed over the D components, minus the quartic coupling ¼β|u|⁴. MultisymplecticIntegrators.SineGordon — Module
SineGordon

The nonlinear sine-Gordon equation c ∂ₜ²u − ∂ₓ²u = −sin(u) on x ∈ [0, l], with the exact solution of the travelling kink.

The Lagrangian density is L = ½(c v² − w²) + 1 + cos(u), and the exact solution is

\[u(t, x) = 4\arctan(\exp(γ (x - v t))), \qquad γ = 1 / \sqrt{1 - c v²},\]

with v = ∂ₜu and w = ∂ₓu its derivatives. γ is a function of c and the kink velocity, so the parameters are (c, velocity) and a kink exists only where c velocity² < 1.

problem = SineGordon.problem(timespan = (0.0, 10.0), timestep = 1.0, xstep = 0.01)

MultisymplecticIntegrators.LinearTransport — Module
LinearTransport

The linear transport equation ∂ₜu + c ∂ₓu = 0 on x ∈ [-0.5, 0.0], whose exact solution is the initial profile shifted by c t.

The Lagrangian density is L = ½u (v + c w). It is a null Lagrangian: its Euler–Lagrange expression vanishes identically, because ∂L/∂u = (v + c w)/2, ∂ₜ(∂L/∂v) = ∂ₜu/2 and ∂ₓ(∂L/∂w) = c ∂ₓu/2. The transport equation is therefore carried by the constraint v = −c w, which the ansatz of the family that integrates this problem imposes, and not by the density alone. The exact solution is the Gaussian

\[u(t, x) = \frac{1}{2\sqrt{\pi}} \exp\!\big(-(x + 2 - ct)^2\big),\]

problem = LinearTransport.problem(timespan = (0.0, 10.0), timestep = 1.0, xstep = 0.01)
