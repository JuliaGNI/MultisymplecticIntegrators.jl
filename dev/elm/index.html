The ELM family

The extreme learning machine of ELM_PDE_int is a NetworkAnsatz in :last_layer mode under WeakInitialAndBoundaryConditions, whose hidden layer comes from the initial guess:

  • the random-feature hidden layer, with the output layer solved, is mode = :last_layer: the step is affine in the output weights;
  • the LSGD training of the hidden layers is the fit method TrainedHiddenLayer: every epoch takes one gradient-descent step on the hidden weights and biases, and then reads the output weights by least squares;
  • the direct least-squares branch is the direct linear solve linear_solver = true on the affine step of a linear density: it factorises the Jacobian at the first step, and again only at a step whose guess has moved the hidden layer.

The family is declined by the method and is kept for comparison: its slab has no root, because the coupling's data rows outnumber what the output weights can satisfy (K44 in KNOWN_ISSUES.md).

TrainedHiddenLayer draws its random features from its own generator, rng = Xoshiro(1234) by default. The run may fail, so the example prints its stats, and nothing reads them.

using MultisymplecticIntegrators

problem = Wave.problem(timespan = (0.0, 0.2), timestep = 0.1, xstep = 0.05)
ansatz = NetworkAnsatz(S = 4, mode = :last_layer, xspan = (0.0, 1.0), degree = 2,
    ncells = (2, 4))
method = SpaceTimeGalerkin(ansatz, WeakInitialAndBoundaryConditions();
    initial_guess = FitTo(PreviousSlab(); method = TrainedHiddenLayer(epochs = 5)))
result = integrate(problem, method)
result.stats
(iterations = [3, 3], residuals = [0.07234094198501365, 0.022296959389017604], initial_residuals = [0.5680890684499115, 11.259849179370503], converged = Bool[0, 0])

epochs = 0 fits the output layer alone on the hidden layer that the generator draws. The same method with the direct linear solve:

method = SpaceTimeGalerkin(ansatz, WeakInitialAndBoundaryConditions();
    initial_guess = FitTo(PreviousSlab(); method = TrainedHiddenLayer(epochs = 5)),
    linear_solver = true)
result = integrate(problem, method)
result.stats
(iterations = [2, 2], residuals = [0.07234094198501363, 0.022296959389017604], initial_residuals = [0.5680890684499116, 11.260348054127753], converged = Bool[0, 0])
