The multiplier network

A NetworkAnsatz is a two-layer network of t̂ and x with S hidden units. Under WeakInitialAndBoundaryConditions the slab's initial and boundary conditions are imposed by multipliers on the ansatz's trace basis, a B-spline basis built from degree and ncells. This is the family of the old NN_PDE_Integrator and NN_PDE_Integrator_Symbolic; their :Fully and :Partially variants are the two values of mode:

  • mode = :all frees every parameter of the network, and the step is a nonlinear system;
  • mode = :last_layer frees the output weights alone and keeps the hidden layer where the initial guess put it, so the step is affine in its unknowns.

The solve of a network step may fail, so each example prints the run's stats, and nothing on this page reads them or claims that a step converges.

using MultisymplecticIntegrators

problem = Wave.problem(timespan = (0.0, 0.2), timestep = 0.1, xstep = 0.05)
ansatz = NetworkAnsatz(S = 4, mode = :all, xspan = (0.0, 1.0), degree = 2, ncells = (2, 4))
result = integrate(problem, SpaceTimeGalerkin(ansatz, WeakInitialAndBoundaryConditions()))
result.stats
(iterations = [69, 62], residuals = [0.07693507195330354, 0.0941367349089493], initial_residuals = [8.027110019933938, 2.8923695506326483], converged = Bool[0, 0])
last_layer = NetworkAnsatz(S = 4, mode = :last_layer, xspan = (0.0, 1.0), degree = 2,
    ncells = (2, 4))
result = integrate(problem, SpaceTimeGalerkin(last_layer, WeakInitialAndBoundaryConditions()))
result.stats
(iterations = [6, 4], residuals = [0.005585414576559082, 0.005472025071823444], initial_residuals = [1.2278153037911612, 0.5531985953930106], converged = Bool[0, 0])

Both modes are declined by the method and are kept for comparison. In :all mode no solver variant converges the step, and the error does not improve where one comes close (K38 in KNOWN_ISSUES.md). In :last_layer mode the slab has no root where the coupling's data rows outnumber what the output weights can satisfy (K39).

The fits

A network is not linear in its parameters, so a Projection is refused on it. Its default_fit is OrthogonalGreedy, the greedy fit of the old OGA2D seed, which Continuation uses at the first slab. TrainedHiddenLayer trains the hidden layer of a :last_layer network (the ELM family), and PINNTraining descends every free parameter (the TrialNN family). The page The initial guess runs each of them.

method = SpaceTimeGalerkin(ansatz, WeakInitialAndBoundaryConditions();
    initial_guess = FitTo(InitialCondition(); method = OrthogonalGreedy(Nw = 10, Nb = 10)))
result = integrate(problem, method)
result.stats
(iterations = [104, 88], residuals = [0.0112823634552112, 0.02533824828025742], initial_residuals = [12.727986871153387, 9.67458659508626], converged = Bool[0, 0])

The regularisation factor

The solver option regularization_factor = λ, passed to integrate beside the method, makes SimpleSolvers' Newton add λ, unscaled, to the diagonal of the slab Jacobian before each factorisation. It is a shift of the Newton matrix, not a Tikhonov term: the residual that a step drives to zero is unchanged. It has two exceptions:

  • the direct linear solve of linear_solver = true factorises the Jacobian without the shift, so λ has no effect there;
  • the fixed-boundary network's LevenbergMarquardt solver does not read it.
result = integrate(problem, SpaceTimeGalerkin(ansatz, WeakInitialAndBoundaryConditions());
    regularization_factor = 1e-8)
result.stats
(iterations = [134, 51], residuals = [0.013428256288760964, 0.033339136670278255], initial_residuals = [8.027110019933938, 2.224152310447694], converged = Bool[0, 0])

The regularisation scan of scripts/network_regularisation_model.jl runs both modes on Wave at four values of λ, as rows of the benchmark matrix.
